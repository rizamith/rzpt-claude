# analises/ — relatórios

Um ficheiro por análise: `YYYY-MM-DD-<assunto>.md`.

Aqui vive o que sai de um pedido de "análise" ou "revisão" — o relatório completo, com os
números que o sustentam. Uma análise que só existe no chat perde-se, e a seguinte não tem
com que se comparar: é a comparação entre relatórios que mostra se uma recomendação pegou.

**O que isto não é:** não é sítio para números novos. Os números vivem em `dados/*.csv` e a
narrativa do dia em `registos/`. Um relatório *lê* dessas duas fontes e interpreta-as — se
um número só existir aqui, está no sítio errado.

Como qualquer coisa escrita neste repositório: **não se reescreve um relatório antigo.** Uma
análise de outubro estava certa com os dados de outubro. Se a conclusão mudou, isso é a
análise seguinte a dizê-lo.
